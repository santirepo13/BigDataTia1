# Guion para una sustentación de aproximadamente diez minutos

Este guion organiza la grabación requerida; no sustituye la participación ni la explicación personal de los integrantes.

| Tiempo | Contenido y demostración |
|---|---|
| 0:00–0:45 | Todos se presentan brevemente con rostro o avatar. Explicar el caso Gaseosas Poderosas y mencionar la contribución real de cada persona. |
| 0:45–1:40 | Mostrar el diagrama de Chen. Explicar una relación 1:M y por qué `temporal` no se conecta mediante FK. Mostrar `regiones`. |
| 1:40–3:20 | Ejecutar el ETL en una base vacía preparada para la demostración. Mostrar el CSV, las funciones conservadas, el arreglo de comillas y los conteos finales. No usar una base con trabajo que se quiera conservar. |
| 3:20–4:40 | Mostrar registros reales de cada tipo de error. Explicar el promedio de Sotara, por qué los dos ceros reciben 79 y cómo se conserva la causa. Reconocer la ambigüedad de la fecha 16558. |
| 4:40–6:25 | Ejecutar consultas en Query Tool de pgAdmin. Mostrar `GROUP BY`, filtros, orden y uso exclusivo de la vista. Comprobar las 10.000 filas de la vista y la tabla. |
| 6:25–7:40 | Abrir el Excel. Explicar una fórmula de participación y de acumulado. Mostrar una torta regional y distinguir monto de unidades. |
| 7:40–8:35 | Ejecutar `algoritmo-calculo-tamanio.py --registros 10000 --prefijo mediciones_video`. Mostrar inicio y fin del contador de tiempo, resultado y consulta del tamaño. Explicar el entorno utilizado. |
| 8:35–9:35 | Explicar dos resultados comerciales con sus límites y acciones propuestas. No afirmar causas poblacionales ni rentabilidad sin esos datos. |
| 9:35–10:00 | Cierre con aprendizajes personales y vista del repositorio que contiene todos los productos. |

Repartir estos segmentos de acuerdo con el trabajo real de cada integrante. El informe no debe leerse de principio a fin. La rúbrica exige ver los programas y SQL funcionando, además de la participación de todas las personas.
